# Project 1 — Data Cleaning & Preparation

## Project Overview

This project focused on cleaning and preparing a raw business sales dataset for further analysis.

The objective was to identify and address common data quality issues that could affect the accuracy and reliability of subsequent analysis.

## Objectives

The project focused on:

- Identifying missing and null values
- Detecting and removing duplicate records
- Correcting incorrect or inconsistent data formats
- Preparing the dataset for further analysis

## Data Cleaning Process

### 1. Missing Values

The dataset was inspected for missing and null values.

Missing values were identified and handled appropriately based on the characteristics of the affected data and the requirements of the analysis.

### 2. Duplicate Records

The dataset was checked for duplicate records to ensure that repeated entries did not distort the analysis.

Duplicate records were identified and removed where appropriate.

### 3. Data Formats

The data types and formats of relevant variables were reviewed and corrected where necessary.

This included checking:

- Date formats
- Numerical values
- Text fields
- Consistency of data entries

### 4. Data Preparation

After addressing the identified data quality issues, the dataset was reviewed to ensure that it was suitable for subsequent analysis.

The cleaned dataset provided a more reliable foundation for the business analysis performed in Project 2.
