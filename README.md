# Decode Labs Internship Projects

This repository contains the data analytics projects I completed during my internship with **Decode Labs**.

The projects involved working with business sales data and applying different stages of the data analytics workflow, from preparing and exploring raw data to performing business analysis and communicating insights through visualizations.

I completed two projects as part of the internship acceptance requirements.

## Projects

### Project 1 — Data Cleaning & Exploratory Data Analysis

The first project focused on preparing the sales dataset for analysis and understanding the underlying structure and characteristics of the data.

The project involved inspecting the dataset, identifying and addressing data quality issues, cleaning and preparing the data, and conducting exploratory data analysis to understand patterns, distributions, relationships, and potential issues within the dataset.

**Key activities:**
- Data inspection and understanding
- Data quality assessment
- Data cleaning and preparation
- Handling missing or inconsistent data
- Identifying potential anomalies and outliers
- Examining data distributions
- Descriptive statistical analysis
- Exploring relationships between variables
- Drawing initial observations and findings from the data

**Tools:**
- Python
- Excel

### Project 2 — Business Analysis & Data Visualization

The second project focused on using the prepared sales data to answer business questions, identify meaningful patterns, and communicate findings through data visualizations.

The analysis moved beyond exploring the dataset to interpreting the results from a business perspective and translating analytical findings into actionable insights.

**Key activities:**
- Business problem analysis
- Defining and answering business questions
- Sales performance analysis
- Customer and order analysis
- Identifying trends and patterns
- Comparing relevant business metrics
- Data visualization
- Interpreting analytical results
- Generating business insights
- Communicating findings and recommendations

**Tools:**
- Python
- Excel
